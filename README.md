同样是2核2G，韩国首尔那台EPYC 7A23的sysbench单核3933分，美国1区那台E5-2680v4只有870分，同工具下差4.5倍。两者价格区间接近（美国1区标准版34元/月），性能差距却是一个数量级。挑雨云时看配置不如看机房，这条在跑分上体现得最直接。

**多线程倍率是判断超售的关键指标。** 一台2核机器，多核分应该接近单核的两倍。香港五区GB6倍率1.77、襄阳1.81、美国1区1.94、韩国1.93、襄阳LemonBench 1.99，全部落在接近2的区间。测评者对香港五区的判断是“多线程倍率接近2倍，说明CPU分配较为真实，没有明显超售痕迹”。如果厂商严重超售，第二个核在跑分时会被邻居抢走时间片，多核分会明显低于单核的两倍，有的机器只剩1.2～1.4倍。雨云这几台没出现这个现象。

跑分绝对值本身没什么惊喜。EPYC 7K62、7A23、7702、Xeon 8259CL、E5-2680v4，都是公开可查的服务器型号，第三方测评数据到处都有。真正需要留意的是“哪个机房配了哪颗U”。

游戏云走的是另一条路。Minecraft的Java引擎吃单线程，雨云给游戏云配i9-14900K，Geekbench单核6800+、多核27000+，单核分是普通VPS那几颗服务器U的六倍以上。多花的钱买的是主频，不是核心数。

## 带宽和线路：500M是不是真的，延迟落在什么水平

香港五区的实测数据最能回答“标称带宽虚不虚”。标称500Mbps的入门款，Speedtest下载峰值485.99Mbps、上传峰值365.34Mbps，接近标称值。测评结论是“实测接近标称带宽，属于真实大带宽线路”。这机器拿来跑下载站、镜像同步或者API中转是够的。

延迟就不好看了。三网平均139ms，上海移动最低34ms。去程电信和联通都绕日本，移动直连香港；回程电信走163绕路、联通绕美国、移动绕日本。移动用户用起来最顺，电信和联通用户要接受绕路带来的额外延迟。这条线路适合对带宽敏感、对延迟不敏感的业务。

湖北襄阳是另一个极端。50M套餐实测Speedtest下载95.78Mbps、上传50.43Mbps，中科大测速站测得下载104Mbps、上传52.9Mbps，跑出了标称的两倍。三网平均延迟31ms，最快的湖北武汉电信只有6ms。襄阳走电信单线，联通和移动用户的实际体验会打折。

美国1区即便做了三线优化，物理距离摆在那儿。平均延迟200ms上下，带宽实际跑不满标称值，损耗到60%～70%很常见。要拿它做大流量业务，得把这个损耗算进成本。

韩国首尔是个例外，延迟和带宽都不错，但有个明确的短板：回程存在重传，电信和移动的重传率普遍高于20%，高峰期容易抖动。测评者的原话是“适合需要原生IP、低延迟的轻量业务，不适合大流量长期跑满带宽”。跑API调用、做轻量代理没问题，挂持续满带宽的下载任务会难受。

## 六项容易多花钱的地方

**NAT不等于独立公网IP。** 雨云不少机型默认NAT模式，共用公网IP，只能开固定数量的端口映射，一般10～15个。学习Linux、内网穿透、开游戏服够用，但**不能直接搭网站**。海外独立IP是5元/个/月，香港移动高防IP 40元/月，宿迁独享IP因为带150G防御要150元/月，比服务器本身还贵。下单页面上“NAT”和“独立IP”这两个词要盯住。

**大带宽限流量和小带宽不限流量同价。** 香港2区2核2G的两种计费类型价格一样，一种给50M带宽配100GB月流量，另一种给10M上传但不限流量。选错方向，钱花了但买的是自己不用的东西。流量用不完可以结转到下月，用完会被限速到5Mbps，买流量包能恢复。流量包单价各家测评口径差异太大，按机房和机型分别定价，这里不写具体数字，下单页看。

**硬盘扩容单独计费。** 默认30GB，扩容按高速固态0.4元/GB/月、机械0.1元/GB/月（另一处记录为固态0.3～0.4元/GB/月）。跑数据库或存镜像的话这笔钱要提前算进去。

**海外节点基本没有防御。** 香港五区明确标注“无防御”。高防集中在内地：宿迁独享150G、宁波和十堰100G级、襄阳200G。业务被打的话，海外便宜机器救不了。

**国内机房必须备案。** 宿迁、镇江、宁波、十堰、重庆都要求域名备案后才能对外提供网站服务。香港、日本、韩国、德国、美国免备案。做数据库、测试环境这类不绑域名的用途不需要备案。

**系统支持有区域差异。** Linux和Windows都能装，宝塔、1Panel可一键部署。想装macOS只有香港2区、香港4区和湖北十堰支持，其他区域不行。

## 常见问题

**雨云的CPU会超售吗？**
从可查的第三方跑分看，2核机器的多线程倍率普遍在1.77～1.99之间，接近理论值2。严重超售的机器这个数字会掉到1.3左右。目前没有明显超售的证据，但这只是几个机型的抽样，不等于所有节点。

**标称500Mbps的香港五区真能跑到500M吗？**
第三方实测下载峰值485.99Mbps、上传365.34Mbps，接近标称。上传那一项距500M还有距离，跑满带宽的业务要留余量。

**流量用超了会直接停机吗？**
不会。用完会限速到5Mbps（部分机型描述为1M），买流量包可以恢复。本月没用完的流量能结转到下月。

**国内机房一定要备案吗？**
要。宿迁、镇江、宁波、十堰、重庆都要求备案。只做数据库、测试、内网服务这类不绑域名对外提供网站的用途，不需要备案。

**能装Windows和宝塔吗？**
Linux和Windows都能装，宝塔、1Panel一键部署。想装macOS只有香港2区、香港4区和湖北十堰支持。

**和阿里云、腾讯云差在哪？**
差在品牌背书和SLA层级。第三方测算同配置价格通常低20%～30%，而且雨云的年付折扣是长期一致的，没有首年低价、续费翻倍那套。
